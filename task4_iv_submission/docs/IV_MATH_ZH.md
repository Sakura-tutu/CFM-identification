# 二元无干扰 IV：LATE 与 ATE 界限

## 1. 变量与目标

工具变量 `Z`、实际处理 `D` 和结果 `Y` 均取值于 `{0,1}`。个体的潜在处理为 `D(0), D(1)`，潜在结果为 `Y(0), Y(1)`。一致性和排除限制对应观测关系 `D=D(Z)`、`Y=Y(D)`；无干扰表示一个人的结果不受其他人的处理状态影响。

这里区分两个目标：

- `LATE = E[Y(1)-Y(0) | D(1)>D(0)]`，即遵从者局部平均处理效应。
- `ATE = E[Y(1)-Y(0)]`，即总体平均处理效应。

## 2. LATE 的点识别

Wald 公式需要以下识别条件：一致性、无干扰、工具变量独立性、排除限制、单调性 `D(1) >= D(0)`，以及 `Z=0` 和 `Z=1` 均有正概率。还需要正的第一阶段：

`E[D|Z=1] - E[D|Z=0] > 0`。

在这些条件下，

`LATE = {E[Y|Z=1]-E[Y|Z=0]} / {E[D|Z=1]-E[D|Z=0]}`。

该比值识别的是遵从者效应，而不是 ATE。若第一阶段为零，比值不能识别 LATE。若在既定编码和单调性假设下第一阶段为负，应报告编码或假设冲突，不应在程序中自动交换工具变量编码。

## 3. ATE 的潜在响应类型线性规划

令潜在响应类型为 `t=(d0,d1,y0,y1)`，每个分量均属于 `{0,1}`。不施加单调性时共有 16 类；施加 `d1>=d0` 后，处理响应组合只剩三种，因此共有 12 类。记类型概率为 `p_t`。

类型概率满足：

- `p_t >= 0`；
- `sum_t p_t = 1`；
- 对每个 `z,d,y`，`P(D=d,Y=y|Z=z) = sum_{t: d_z=d, y_d=y} p_t`。

ATE 的目标函数为：

`ATE = sum_t p_t (y1-y0)`。

分别最小化和最大化该线性目标，得到给定潜在响应类型模型下的 ATE 上下界。约束集合是概率单纯形与线性等式约束的交集；若该集合非空，它是紧致的，因此线性目标的两个端点均可达到。求解器返回的端点类型概率向量是相应的可行构造。

这里的 sharpness 指在上述声明的有限潜在响应类型模型内，端点可以由可行类型分布达到；它不表示识别假设已经由数据验证。

## 4. 输入与停止规则

输入为八个条件概率单元 `(z,d,y) -> P(D=d,Y=y | Z=z)`。每个 `Z` 组的四个概率应非负且总和为 1。输入应是总体条件分布；本实现不会把样本频数自动转换为总体概率。

- LATE 假设未获调用方确认时，函数停止计算。
- 第一阶段为零时，不返回 LATE 点估计。
- 在单调性和当前编码下第一阶段为负时，报告方向冲突。
- ATE 线性规划不可行时，说明观测分布与所声明的潜在响应类型模型不相容，不返回上下界。
- LATE 与 ATE 是不同 estimand，应分别报告。

## 5. ATE 端点证书

求解器返回下界和上界对应的 primal 类型概率向量，以及线性规划等式约束的对偶变量。对下界问题 `min c^T p, A p=b, p>=0`，对偶可行条件为 `A^T lambda <= c`；对上界问题，使用 `A^T mu >= c`。

验证器检查 primal 非负性、观测约束、概率归一化、dual 可行性，以及 primal 与 dual 目标值是否在数值容差内相等。若这些条件同时成立，弱对偶性给出相应端点的最优性证书。该检查针对求解器构造的有限线性规划，不是对 IV 科学假设的验证。
